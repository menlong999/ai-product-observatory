# AI Product Observatory 周报｜2026-W35

观察周期：2026-08-24 至 2026-08-30

本周最大的变化不是新 Agent 数量，而是生产级 Agent 的两条基础链开始清晰：**Control Chain 决定它能不能做，Assurance Chain 独立证明它做对没有。**

## Top 3

1. **Agent Control Plane 正式成为产品类别**：Decawork 与 Traccia 同周出现，并直接围绕集中控制、policy、runtime control、audit 定义产品。连续六周的治理信号开始收敛成明确基础设施层。
2. **Executable Verification 升级为 Independent Assurance**：Agnost 从生产会话发现 eval 未知失败，Lenz 做独立事实复核，PromptBrake 把 AI 行为验证做成发布 gate。generator 自证正在失效，独立 evidence 才是接受条件。
3. **Context 从 Memory 分化成专业 Data Plane**：GitNexus、Flare、Firecrawl Developer Index 分别做 code graph、change/dependency graph、external developer index。长期价值越来越来自结构、来源、freshness 与 query semantics。

## 与历史相比，本周发生了什么

### Agent Control Plane：连续第六周升温

W30 的 secret isolation，到 W31 的 Skill/Eval/data authorization、W32 的 gateway/approval/recovery、W33 的 sandbox/action gate、W34 的 endpoint/repo/employee agent，W35 终于出现 Decawork 与 Traccia 直接使用 **Agent Control Plane** 这个类别名称。

当前判断：这已经不是 security/observability 的功能集合，而是生产 Agent 的基础设施层。

### Verification：从 Executable Verification 升级为 Independent Assurance

过去四周从 Trace/Score 逐步进入真实执行、PR/release QA。本周 Agnost、Lenz、PromptBrake，以及 Hacker News 上的 Terminal-Bench-Science，把验证扩到 production failure discovery、事实复核、安全发布与真实科研 workflow。

共同原则更清晰：**generator 不能自己给自己打分，结果必须由独立 evidence 决定是否接受。**

### Context：Shared Agent Data Plane 开始专业分层

W30—W34 主要是组织知识、配置、共享 memory 与 live business data。本周 GitNexus、Flare、Firecrawl Developer Index 把它拆成 code graph、change/dependency graph、external developer evidence index。

判断修正：Memory 只是 Data Plane 的一个子能力。长期价值在 structure、source、freshness、scope、lineage、ACL 与 query semantics。

### AI FinOps：重新升温

W34 一度降温，本周 Navigara 直接把 AI spend 绑定 roadmap item、capacity gain 与 maintenance burn；Diet Claude、TokenPulse 又补充 quota 与 usage visibility。

真正值得跟的不是 token dashboard，而是 **cost per accepted outcome / roadmap item**。

### 首次信号：Teach-by-demonstration Process Capture

Caddi 通过一次 screenshare 学流程，再生成 production agent。它比“再做一个 workflow builder”更值得看，因为它在尝试把企业 tacit process 转成可执行规范。

目前只有一个强样本，继续观察。

### Persistent Specification 暂不升级

W34 Huzzah 的 Intent-as-Source 没有出现第二个同等清晰实现。多 Agent context 与 dependency context 在增长，但并不等同于 human intent 作为长期一等工件。

### Agent Commerce 回到 watchlist

Purchase API by Agentcard 本周再次提供 purchase rail 信号，但订单身份、退款、争议、责任归属仍缺连续证据，暂不回核心趋势。

## 下周观察

- Control Plane 是否出现统一 capability / policy / run schema。
- Independent Assurance 是否形成 evidence schema、release gate protocol 或 verifier API。
- Code graph 是否成为 coding-agent 默认 context primitive。
- FinOps 是否出现更多 cost-per-accepted-change / business-outcome 产品。
- Teach-by-demonstration 是否出现第二、第三个独立实现。
- Agent Commerce 是否补齐身份、退款、争议与责任闭环。
