# AI Product Observatory 周报｜2026-W36

观察周期：2026-08-31 至 2026-09-06（周日早间截点）

本周最值得关注的变化，是生产 Agent 从 Control + Assurance 两条链继续长出第三条：**Learning Loop**。Agent 不只要被控制、被验证，还要决定哪些真实运行经验值得改变未来行为。

## Top 3

1. **Agent Learning Loop 首次形成产品簇**：Reflexio 与 Blume.codes 同周把用户纠正、失败、成功提炼成 reusable behavior、rules、skills，并强调可测试、可逆。长期 Agent 配置开始从“人工维护”走向“运行反馈产生候选，再经过 promotion”。
2. **Agent Control Plane 进入 execution-path enforcement**：Doberman 与 Aegisora 2.0 都把 policy engine 放到 action 真正执行之前。连续第七周升温，但 runtime allow/block 开始向开源基础能力商品化。
3. **Independent Assurance 变成 Evidence-native 产品要求**：Airtop 在自动修复后跑真实测试，HyperProbe 从生产系统抓只读 evidence，Basedash 把 query/source receipts 直接展示给用户。Assurance 正从独立工具变成高风险 Agent 的产品内建能力。

## 与历史相比，本周发生了什么

### 没有同名连续上榜，但类别连续性更强

W35 Top 10 与 W36 Top 11 没有完全同名产品。连续性发生在 Control Plane、Verification/Evidence、Data Plane、Agent-native SDLC 等问题类别上，而且由不同团队重复实现。

这比同一个产品持续上榜更能说明问题已经进入真实产品需求阶段。

### 首次形成：Agent Behavior Supply Chain

Reflexio 与 Blume.codes 同周把运行反馈变成未来执行规则。它与此前两个方向有关，但应区分：Persistent Specification 是长期 intent，Teach-by-demonstration 是从演示捕获流程，Learning Loop 是从真实运行结果提炼候选规则。

当前判断：首次形成独立观察方向，暂命名 **Agent Behavior Supply Chain**。

### Agent Control Plane：连续第七周升温

上周 Decawork、Traccia 让 Agent Control Plane 这个类别名称被市场确认；本周 Doberman、Aegisora 2.0 又把 enforcement 下沉到 execution path，而且采用开源路线。

判断修正：runtime allow/block 会快速成为基础能力。更持久的价值会向 identity、policy distribution、exception approval、evidence、compliance、retirement 上移。

### Independent Assurance：从独立层变成产品内建要求

Airtop、HyperProbe、Basedash、GitWarren 并不是四个“Eval SaaS”，但都把 evidence 或 acceptance gate 放进主工作流。

当前判断：未来任何产生真实 side effect 或高价值结论的 Agent，都需要原生的 **evidence surface + acceptance gate**。

### Agent-native SDLC：从执行推进到 review / debug / learning

W34 是 Git forge、worktree、delivery substrate，W35 是 code graph 和 review surface，本周 GitWarren、HyperProbe、Blume 继续推进 pre-commit review、production debugging、session learning。

竞争焦点越来越不是“能写多少代码”，而是“能不能把大量 Agent change 纳入可靠的软件工程闭环”。

### Shared Agent Data Plane：继续升温，但增量变得更细

Almanac 延续企业知识层；Basedash 强化 provenance；Reflexio/Blume 又让 behavioral lessons 成为长期数据资产。

因此 Data Plane 里开始同时出现 fact、policy、skill、lesson、evidence。它们需要不同 schema、ACL、versioning 与 lifecycle，不能简单混进同一个 vector store。

### MCP：协议层继续扩散，产品类别降温

本周仍有大量 MCP 相关产品，但“支持 MCP”已经很难构成差异。Monid 更值得看，因为它把价值移到 capability discovery、routing、metering 与 payment。

### AI FinOps：再次回到观察

上周 Navigara 带来 outcome-attribution 强信号，本周没有第二个同等级商业样本。FrontierHarness Eval 则提醒成本应该看 cost per successful outcome，而不是只看 token price。

### Teach-by-demonstration：暂未出现第二个直接样本

Caddi 之后，本周没有第二个等价 demonstration capture 产品。Reflexio/Blume 更接近 feedback learning，不应为了凑趋势合并。

### Generic No-code Workflow：判断微调但不反转

Airtop 是有效反例：简单的自然语言 workflow authoring 在商品化，但 compile → diagnose → repair → real-run verify 的可靠闭环仍然有价值。

### Agent Commerce：继续 watchlist

Monid 的 tool-level payment 属于 capability economics，不等于完整 consumer commerce。身份、退款、争议和责任归属仍缺连续证据。

## 下周观察

- 是否出现第三个 Agent Learning / behavioral rule 产品。
- Learning Loop 是否形成 test、scope、promotion、rollback 等明确 schema。
- Control Plane 是否从本地 enforcement 进入组织级 identity + policy distribution + evidence。
- Evidence-native UX 是否扩展到客服、采购、运营等非 coding 场景。
- Agent-native SDLC 是否出现统一的 change / evidence / review object。
- Capability router 是否加入 permission、budget、reputation、SLA 等治理能力。
- AI FinOps 是否重新出现 cost-per-success / accepted-outcome 的商业产品。
