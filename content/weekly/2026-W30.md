# AI Product Observatory 周报｜2026-W30

观察周期：2026-07-20 至 2026-07-26

## Top 3

1. **OneCLI**：Agent 凭据隔离从附加安全能力变成基础设施。2.5K+ GitHub Stars、30 万+下载、YC S26。
2. **Bento**：一个 HTML 文件同时是文档、编辑器、播放器和数据载体，重新定义文件与软件的边界。
3. **AI Toolbox**：两人团队，35,000+ 活跃用户、五位数 MRR，基础设施约 45 美元/月。

## 本周趋势变化

### Coding Agent 周边集中爆发

OneCLI、Kastra、Pushary、Heard、Openbase、Capsomnia、Claude-thermos、Remux、Palmier Pro、CodeAlmanac 在一周内连续出现。竞争从模型写代码能力转向凭据、权限、监督、状态、缓存、持续运行和项目上下文。

### Enterprise Context / Memory 持续升温

CodeAlmanac、Moxie Docs、Fluree AI、PromptQL、Second Brain 的共同点不是“存更多内容”，而是强调来源、权限、更新、冲突、删除、Git Review 和确定性查询。

### Agent 值守首次形成独立类型

Pushary、Heard、Openbase、Capsomnia 集中解决长任务和多 Agent 并行之后的人类注意力问题。

### AI 视频开始分化

单次生成型工具继续同质化；Palmier Pro、Buzzy 这类保留时间线、角色、场景和项目状态的产品获得更强持续信号。

### 降温与退出观察

通用 AI Wrapper 缺少新的技术和商业信号。ditto.site、Manifest 有强单日讨论，但没有形成跨来源连续验证，暂不升级为长期趋势。
