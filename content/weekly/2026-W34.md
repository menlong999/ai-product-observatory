## 跨周变化

### Agent-native SDLC 首次形成

Origin、Proliferate、Clears、Epho、Checksum 开始覆盖 Git forge、worktree orchestration、cloud agent runtime、agentic delivery 与 continuous verification。过去拆开的 Coding Agent、Control Plane、Eval 正合并成一条新的软件生产链。

### Executable Verification 集中爆发

W31 是 Trace / Score，W33 进入真实环境执行，W34 的 Checksum、Replay QA、Superflow AI 连续出现。判断升级：Executable Verification 正成为 Agent-native SDLC 的固定阶段。

### OneCLI 从 W30 再次出现

W30 核心是 secret isolation；W34 以 secured, sandboxed employee assistant 再次进入强观察。说明 Control Plane 从开发者基础设施继续扩展到企业个人 Agent。

### Agent Control Plane 连续第五周升温

OneCLI、Plow Latch、Proliferate 继续强化 sandbox、scoped access、worktree、supervision 与 self-hosting；控制面从中心平台继续下沉到 desktop、repo 与 employee agent。

### Context 继续演进为 Shared Agent Data Plane

CodeAlmanac → MemoryCustodian → Hexis → Xirp → OzBrain / Supernova。Context 从 repo-owned knowledge 走到跨 Agent 共享知识和 live business data。

### 首次信号：Intent-as-Source

Huzzah 指出 Prompt 会消失、Source Code 又不能表达人的原始意图。Persistent Spec 可能成为 AI-native repo 的新工件，但目前只有单一强样本，暂不升级为长期趋势。

### 判断修正

- Autonomous Software Maintenance 这个分类过窄，改为更大的 Agent-native SDLC。
- Browser Execution 越来越像 QA、Research、Operations 共用的 execution adapter，不再单列一级趋势。
- Runtime FinOps 本周缺乏同级产品簇，从核心趋势降到观察。
- Agent Commerce、Generic No-code Agent Workflow 继续退出核心观察。
