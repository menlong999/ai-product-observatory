### 1. Plurai Simulation

- 来源日期：2026-11-11（官方）；11-12（PH）
- 分类：Agent Evaluation / Stateful Simulation
- 产品：从 agent 代码和工具契约生成共享状态的模拟世界，用户场景、工具读写与最终状态评测相互一致。
- 已核验发布/材料：官方发布 Claude Code、Codex、Copilot 插件；模拟在本地启动真实 agent，后端生成世界与评测。 代码/凭据相关工作在本地，但 plurai_sim/、选择加入的资料及模拟对话会传到后端，不是全离线。 mock、real、observe 三类连接必须区分；real/observe 会运行真实工具，不能泛称绝不触碰真实系统。
- Launch / Discussion Signals：PH 11月12日第1，411 upvote points；观测2026-11-15。没有独立留存/收入证据。
- Creator Story：Ilan Kadar 与 Elad Levi 自述将自动驾驶仿真经验转向 agent 长尾故障；不是以融资作为入选理由。
- 为什么重要（研究判断）：W42 Tiden、W44 Simantic 的可核验执行，向软件 agent 的有状态环境模拟延伸。测试应证明动作后世界如何变化，而不只判断说得对不对。
- What can be learned：每场景共享状态；最终状态作为证据；版本锁定模拟与代码；保留人工接受修复边界。
- 限制与未核实：未实测；82%故障减少、97%成本下降及40x/44x对比均厂商自报，无公开同条件独立复验，不作为通用收益。连接页本轮不可读，官方两篇全文可读。

Standalone AI FinOps、Agent Commerce、Physical-world Data Plane仍未获本轮足够新证据升级一级观察；演示捕获也不能因“self-improvement”词汇流行而直接升级。W45 Tobira/Floot/Pauta的首发热度未在本轮获得可独立核实的留存/收入后续，不循环复述。

## 判断修正：之前 / 本周 / 证据

1. 之前W44–45对自动行为学习保持谨慎。本周保留谨慎，但不再笼统视为缺实现：Kapso和AgentRun可查经验边界、准入、版本、撤销；仍缺长期受控收益，因此只提高实现研究优先级。
2. 之前验收关注正确run/build与完整输入。本周补充：还需检查真实动作后最终状态，和修复是否引入新故障。证据为Plurai的统一世界状态与three.dev的前后故障对照；后者演示数据不能用作有效性证明。
3. 之前共享事实要有提案权限。本周增加知识分支、schema、merge与历史，但不能从“可审阅”跳到“真事实”：Omnigraph文档只证明机制描述，不证明自动真实性或安全审计完成。
4. 之前只读工具通常风险较低。本周明确收紧：Docker只给精确GET read-only hint，维护者仍声明不保证保密；Deep Agents批量搜索需要检查symlink实际目标及已批准scope。
