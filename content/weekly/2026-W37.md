# AI Product Observatory｜2026-W37

观察周期：2026-09-07 至 2026-09-13（周日早间截点）

本周最明显的变化不是 Coding Agent 又变强，而是围绕它的工作系统、权限系统和证据系统开始真正咬合。

## Top 3

1. **Agent-native SDLC 正升级为 Agentic Software Factory。** Mastra Factory 把 issue intake、persistent coding agents、repo workspace、planning、implementation、PR review、release、docs 与 production monitoring 收进统一环境。W34—W36 的零散基础设施开始系统化。
2. **Control Plane 连续第八周升温，进入 Per-action Authority。** Harden 在 tool call 真正执行前检查风险；Relaticle 把每个 write 变成逐条 proposal；StareBrain 进一步提出 time-of-use revalidation：权限不能只检查一次。
3. **Evidence-native Requirement 正形成 Evidence Spine。** EasySpecs、PR Lens、Replay、QApilot、OpenObserve 分别覆盖 Spec、Review、真实执行、安全验证与 Production Trace，证据开始贯穿整个软件生命周期。

## 与历史相比，本周发生了什么

### Agent-native SDLC → Agentic Software Factory

Mastra Factory 是本周最强信号。过去几周的 worktree、Git forge、review、debug、learning 都是零散部件；现在开始出现把长期 work state、phase gate、handoff、release、production feedback 放进同一系统的产品。

### Control Plane：连续第八周升温

W36 的重点是 execution-path enforcement；本周进一步收紧到 **Per-action Authority**：不仅判断 Agent 有没有某项能力，还要在真正产生 side effect 前确认 actor、object、parameters 与 time window 仍然有效。

### Persistent Specification 重新升温

W34 后样本不足，本周 EasySpecs 提供第二个清晰实现。更合理的方向不是“多写一份文档”，而是把 Spec 做成可验证的 control artifact，同时服务于 Agent context、review boundary 与 acceptance criteria。

### Evidence-native Requirement → Evidence Spine

Spec/Oracle → Architecture Impact → Real-device Test → Security Evidence → Production Trace → Repeated-run Reliability 开始连成一条生命周期证据链。未来“任务完成”的判断很可能依赖这条链，而不是 Agent 自报成功。

### AI FinOps 不恢复为一级趋势

OpenObserve 把 token/cost 与 latency、quality、failure、online eval 一起放入 production observability。成本更像 Agent Observability 的一个维度，而不是独立价值中心。

### Shared Agent Data Plane 继续升温

Thousand 强化 Context ACL；Mireye 则把 Data Plane 明显延伸到 physical world。后者暂时只有一个强样本，先进入观察。

### 降温与退出

- Agent Behavior Learning：本周没有第三个直接 feedback-learning 产品，降到观察。
- Capability Router / Tool Marketplace：没有第二个 Monid 级样本，不升级。
- MCP：继续广泛出现，但越来越像 plumbing，而不是产品差异。
- Teach-by-demonstration：连续两周无新强样本，退出重点观察。
- Agent Commerce：没有足够连续证据恢复核心趋势。

## 下周继续观察
