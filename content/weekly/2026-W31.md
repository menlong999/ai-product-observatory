# AI Product Observatory 周报｜2026-W31

观察周期：2026-07-27 至 2026-08-02

## Top 3

1. **localskills.sh**：Skill 开始成为有版本、权限、来源和审计要求的团队资产。
2. **Prefactor**：把 Agent Evaluation 放进每次生产运行，竞争从离线模型分数转向线上质量回归。
3. **MarbleOS**：用文件、任务、工具和输出构成可见工作区，代表 Agent 产品从 Chat-first 转向 Workspace-first。

## 本周趋势变化

### Coding Agent 基础设施进入 Control Plane

上周主要解决凭据、持续运行和远程监督；本周的 localskills.sh、Prefactor、Prelint、DepthData、Rivault 把重点推进到版本、评测、决策门禁、成本归因和数据授权。

### Context / Memory 判断得到验证

CodeAlmanac 强调 Repo-owned Markdown；本周的 MemoryCustodian、Greplica 等继续强调来源、选择性加载、更新和审查。单纯“记住更多”不是方向，能够维护和证明上下文才是。

### Agent Evaluation 首次形成产品组

Prefactor、Cekura、TraceLLM 集中覆盖运行追踪、质量评分、根因定位、配置修正和回归验证。没有回归验证的“自我改进”只是自动修改。

### Skill 供应链与 MCP 运营层首次形成

localskills.sh 处理 Skill 的分发、版本和权限，MCP-Billing 处理 MCP 的身份、限流和计费。Skill 与 MCP 正从个人配置和 Demo 进入可运营资产。

### Agent 值守继续演进

上周的产品主要解决完成提醒和远程审批；MarbleOS 进一步把任务、文件、工具和输出放进同一工作台。

### 降温与退出核心观察

Agent Commerce 没有出现退款、售后或订单身份的新验证；AI 视频的真实可编辑时间线没有得到新的强信号；通用 Wrapper 继续数量多、有效差异少。

## 历史对比

### 连续出现

- Coding Agent 周边连续两周最密集，但从 Runtime 周边升级为治理控制面。
- Context / Memory 继续从“存储更多”转向 Repo-owned、选择性加载和可审查。
- Agent 监督从通知与审批，向任务、文件、输出可见的工作台演进。
- Agent 安全从秘密隔离，扩展到逐次敏感数据授权。

### 首次出现

- 生产 Agent 的持续评测、回归和自我改进闭环。
- Skill 的企业级分发、版本、权限和运行证明。
- MCP Server 的身份、计费、限流和密钥轮换。
- 企业 AI 使用与成本的统一 System of Record。

## 下周继续观察

- Skill Registry 是否出现版本固定、加载证明和供应链安全机制。
- Agent Eval 产品是否披露真实回归率、误报和人工介入成本。
- Repo-owned Context 是否形成团队协作、过期清理和冲突处理。
- Workspace-first 产品是否比 Chat-first 产品获得更高留存。
- 企业 AI Spend 产品是否能连接业务结果，而不只是统计 Token 和席位。
