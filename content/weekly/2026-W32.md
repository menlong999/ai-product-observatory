## Top 3

1. **Hexis**：把 skills、tools、context 放入同一套 Git-backed、可 Review、可授权的治理层。
2. **AgentSky**：长任务 Agent 托管进入快照、恢复和多渠道阶段，生产问题开始转向进度判定与副作用幂等。
3. **AI Spend Console by Rippling**：把 AI 成本与 GitHub PR、revision 等工程产出关联，验证 AI FinOps 必须连接业务结果。

## 本周趋势变化

### Agent Control Plane 从可见走向可执行

上周重点是 Skill 版本、Eval、权限和成本；本周 ngrok AI Gateway、Soloop、AgentSky、Cloudflare OS 把控制面落到网络入口、动作审批、运行状态和恢复语义。真正的控制面必须能阻断、恢复和记录行为，而不只是展示状态。

### Skills 与 Context 开始合流

localskills.sh 与 MemoryCustodian 上周还是两个方向；Hexis 本周直接把 skills、tools、context 放在同一个 Git-backed、可 Review、可授权的管理面。长期对象更像 Agent Configuration Supply Chain。

### AI FinOps 开始连接业务结果

DepthData 上周主要统一成本、采用和质量；Rippling 本周把 AI spend 与 GitHub PR、revision 等工程产出关联。单纯统计 Token 和席位的价值会快速下降。

### Autonomous Software Maintenance 首次形成

Coldtea.ai、Superlog Responder、Muse Code 同周指向持续修复、维护和长时 Coding Agent。但 self-driving 只有在 Eval、审批、回滚与副作用控制存在时才可信。

### Evals / Observability 基础设施化

Prefactor、Cekura 之后，本周又有 Progress AI Observability 和 Show HN Armature。Trace/Eval 正变成标配，差异会转向业务 ground truth、质量门禁和失败处置。

### Agent Commerce rails 重新进入观察

上周因退款、售后、订单身份缺失而降温；本周 Cloudflare Wallets 与 UCP Radar 从钱包和商品可见性补基础设施。Commerce 尚未升温，但观察对象正在从购物 UI 转向支付与发现协议。

### 多 Agent 协作走向共享执行面

Kiro Crew、Murmell、mpai、HAR、CopilotKit Channels SDK 集中处理多人、多 Agent、跨渠道协作。Workspace-first 正从可见性推进到共享任务状态、对象和执行权限。

## 历史对比

### 连续出现

- Agent Control Plane 连续三周增强：凭据/值守 → 版本/Eval/权限 → Gateway/审批/运行恢复。
- Context Lifecycle 从 CodeAlmanac → MemoryCustodian → Hexis，逐步收敛到 Git-backed、可授权、可 Review 的执行配置。
- Agent Evaluation 从 Prefactor/Cekura → Progress/Armature，继续扩散，但独立产品差异减弱。
- Workspace 从 MarbleOS → Kiro Crew、Murmell、mpai、HAR，开始从单 Agent 可见性转向共享执行状态。

### 判断修正

- Autonomous Software Maintenance 首次形成产品簇，但必须被 Control Plane 约束。
- AI FinOps 从记录花费升级为连接工程/业务产出。
- Agent Commerce 重新出现的是 Wallet、Feed、协议，而不是成熟购物助手。
- Skill 与 Context 不应继续分开建模。
- 纯 MCP Connector 越来越商品化，协议本身不再构成壁垒。

## 下周继续观察

- Hexis 是否出现运行加载证明、冲突处理和企业审计能力。
- 长任务 runtime 是否补 progress semantics 与 side-effect idempotency。
- AI Spend 是否从 PR 数量走向缺陷率、交付周期和真实业务结果。
- Autonomous Maintenance 是否披露回归率、回滚率和人工接管成本。
- Agent Commerce rails 是否补订单身份、退款与争议处理。
